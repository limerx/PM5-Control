# Roadmap

**English** | [Français](ROADMAP.fr.md)

## Phase 1 — Prototype review

- [x] Demonstrate BLE transport on the initial Android test device.
- [x] Identify the firmware and start a matching Iceman client.
- [x] Demonstrate hardware diagnostics and targeted ISO14443-A reading.
- [ ] Investigate intermittent reception errors.
- [ ] Review local server isolation, process lifecycle and dependencies.
- [ ] Review source provenance and licensing.

## Phase 2 — Reproducible experimental release

- [ ] Separate the transport, interface and client lifecycle components.
- [ ] Document authorized setup and supported browser/firmware combinations.
- [ ] Add automated tests for connection states, shutdown and battery parsing.
- [ ] Test extended BLE sessions and reconnections on physical hardware.
- [ ] Verify charging estimates against actual measurements.
- [ ] Publish reviewed source, installation instructions and release notes.

## Phase 3 — Community feedback

- [ ] Collect sanitized compatibility reports.
- [ ] Invite upstream feedback on the browser-based transport.
- [ ] Improve reliability and maintainability based on verified results.

No fixed release date or universal compatibility is promised.
